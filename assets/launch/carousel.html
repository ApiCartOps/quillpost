Quillpost5 / 7
For AI agents

Agents preview. You approve.

1
Agent builds a preview
quillpost_preview publishes nothing
2
You read the exact text
Style, visibility, attachments, warnings
3
You say yes in chat
Only then approved: true is sent

A standard MCP server with 17 tools: works with Claude Code, Cursor, VS Code and more.

A guardrail, not a sandbox: it relies on the agent following instructions.
